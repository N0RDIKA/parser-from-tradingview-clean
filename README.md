# parser-from-tradingview

Автоматическое превращение сигналов торговых стратегий из TradingView в рыночные заявки для торговой системы. Сигнал проходит путь от алерта до файла транзакций без ручного участия.

## Как это работает

```
TradingView (алерт)
   │  вебхук, JSON
   ▼
Google Apps Script ──► Google Таблица
                           │  Power Query, каждые 30 секунд
                           ▼
                       Excel: раскладка сигналов по стратегиям
                           │  VBA, проверка каждые 5 секунд
                           ▼
                       Файл транзакций .tri ──► торговая система
```

1. **Прием сигнала.** Стратегия на Pine Script отправляет алерт на вебхук. Google Apps Script проверяет секретный токен и записывает в таблицу время, инструмент, сигнал и цену.
2. **Загрузка в Excel.** Power Query подтягивает таблицу каждые 30 секунд. Макрос раскладывает сигналы по трем стратегиям: фьючерсы, акции, опционы. Защита от дублей построена на составном ключе (время получения, инструмент, время сигнала).
3. **Формирование заявок.** Каждые 5 секунд макрос ищет необработанные сигналы:
   - `LE` и `LE_ADD` — вход и докупка, рыночная покупка по составу позиций стратегии;
   - `LX` — выход, рыночная продажа.

   Обработанный сигнал помечается `_DONE`, поэтому повторно не исполняется. Сигналы старше заданного возраста (по умолчанию 5 минут) пропускаются, а не исполняются по рынку задним числом.
4. **Хедж.** Для фьючерса на индекс направление заявки инвертируется, а счет и класс инструмента подставляются отдельно.
5. **Файл заявок.** Для каждого инструмента формируется строка `NEW_ORDER` с уникальным `TRANS_ID`. Торговая система забирает файл и выставляет заявки.

## Структура

| Файл | Назначение |
|---|---|
| `google-apps-script/script.gs` | Прием вебхука, проверка токена, запись в таблицу |
| `excel-vba/Config.bas` | Все настройки: листы, ключи стратегий, хедж, интервалы |
| `excel-vba/AutoRefresh.bas` | Обновление Power Query и раскладка сигналов по стратегиям |
| `excel-vba/SignalWatcher.bas` | Проверка новых сигналов и формирование заявок |
| `excel-vba/Orders.bas` | Запись файла транзакций |
| `excel-vba/ThisWorkbook.cls` | Запуск и остановка таймеров при открытии и закрытии книги |

## Установка

1. **Google Apps Script.** Создайте Google Таблицу, откройте Расширения > Apps Script и вставьте `script.gs`. В свойствах скрипта задайте `WEBHOOK_TOKEN`. Разверните как веб-приложение с доступом для всех, полученный адрес укажите в алерте TradingView.
2. **Алерт TradingView:**
   ```json
   {"token":"<WEBHOOK_TOKEN>","ticker":"{{ticker}}","signal":"LE","price":{{close}},"time":"{{time}}"}
   ```
3. **Excel.** Подключите таблицу через Power Query на лист-источник. Импортируйте модули `.bas` (VBA-редактор > File > Import File), а код `ThisWorkbook.cls` вставьте в модуль ЭтаКнига.
4. **Настройки.** Заполните `Config.bas`: ключи стратегий (формула корзины из TradingView) и счет для хеджа. На каждом листе вывода в столбце R укажите путь к файлу `.tri`, класс инструмента, счет и код клиента.

> **Кодировка.** Файлы в репозитории в UTF-8. VBA-редактор при импорте ждет Windows-1251, иначе кириллица превратится в знаки вопроса. Пересохраните `.bas` в Windows-1251 перед импортом или вставьте код через буфер обмена.

## Стек

Pine Script v5, Google Apps Script, Google Sheets, Power Query, Excel VBA.

## Безопасность

Реальные номера счетов, коды клиента и составы стратегий в репозиторий не попадают: они хранятся в ячейках рабочей книги и свойствах скрипта. Рабочие книги и файлы заявок исключены через `.gitignore`.
